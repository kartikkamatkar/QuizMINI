# Quiz Management System

A simple desktop-based Quiz Management System built using Java Swing, JDBC, and PostgreSQL. This project was developed as a college mini project to practice Java programming, database connectivity, and GUI development.

## Features

- Simple login screen
- Load quiz questions from the database
- Four options for each question
- Select answers and move to the next question
- Automatic score calculation
- Display the final score and percentage

## Technologies Used

- **Java** – Application logic
- **Java Swing** – User interface
- **JDBC** – Database connectivity
- **PostgreSQL** – Store login details and quiz questions
- **IntelliJ IDEA** – Development environment

## Database Setup

Create a PostgreSQL database named `quiz_mini`.

Create the `users` table:

```sql
CREATE TABLE users (
    id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(100) NOT NULL
);
```

Insert a sample login account:

```sql
INSERT INTO users (username, password)
VALUES ('admin', 'admin123');
```

Create the `miniquestion` table:

```sql
CREATE TABLE questions (
    id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    question VARCHAR(255) NOT NULL,
    option_a VARCHAR(100) NOT NULL,
    option_b VARCHAR(100) NOT NULL,
    option_c VARCHAR(100) NOT NULL,
    option_d VARCHAR(100) NOT NULL,
    correct_answer CHAR(1) NOT NULL
);
```

Add sample questions to the `miniquestion` table before starting the quiz.

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure JDK 21 and PostgreSQL are installed.
4. Add the PostgreSQL JDBC driver to the project.
5. Create the database and tables using the SQL commands above.
6. Update the database URL, username, and password in `DBConnector.java`.
7. Run `Main.java`.
